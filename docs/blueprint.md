# **App Name**: BennettU Mobile

## Core Features:

- Profile Display: Display student profile information.
- Status Check: Indicate student's current status.
- Personalized University News: AI tool that personalizes the university news feed.

## Style Guidelines:

- Primary color: Deep blue (#19376D) to evoke a sense of trust and reliability.
- Background color: Light blue (#D4E0F0), visibly in the same hue as the primary color, but heavily desaturated for a calm backdrop.
- Accent color: Teal (#30696A) as an analogous color to deep blue, but with different saturation and brightness for emphasis.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text. This offers a modern and neutral aesthetic suitable for conveying information clearly.
- Use clean, minimalist icons related to university life.
- A clean and straightforward layout.
- Smooth transitions and subtle animations on data updates and navigation.
